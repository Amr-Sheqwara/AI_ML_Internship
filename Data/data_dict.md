# Data Dictionary & Dataset Catalog

Managing datasets in Git and GitHub requires a clear separation between code, configuration, and data assets to ensure project reproducibility without bloating repository history.

---

## 1. Data Governance & Architecture Rules

* **Immutability Principle:** Raw data files in `Data/raw/` are strictly **read-only**. Never modify original CSV or image files directly. All cleaning, imputation, scaling, and one-hot encoding must be performed programmatically via Scikit-Learn `Pipeline` and `ColumnTransformer` (`preprocessor`).
* **Processed Data Partition:** Transformed and cleaned datasets generated by code (e.g., `penguins_cleaned.csv`) reside in `Data/processed/` and are excluded from Git history via `.gitignore` to prevent tracking redundant transformed files.
* **Strict Relative Paths:** All scripts and notebooks access datasets using relative paths (e.g., `pd.read_csv("../Data/raw/heart.csv")` or `pd.read_csv("../../Data/raw/1.TitanicDataset.csv")`) so the repository runs portably across any environment.
* **Image Datasets (`Data/Image_dataset/`):** Large image collections are separated in `Data/Image_dataset/` and excluded from Git tracking via `.gitignore`.

## 3. Dataset Catalog & Schema Breakdown

### 3.1 Raw Datasets (`Data/raw/`)

#### 1. Titanic Passenger Survival Dataset (`Data/raw/1.TitanicDataset.csv`)
* **Task:** Supervised Binary Classification (Predicting survival probability).
* **Dimensions:** 418 rows $\times$ 12 columns.
* **Raw State:** Contains $414$ missing values across `Age`, `Fare`, and `Cabin`.
* **Target Variable:** `Survived` ($\text{Binary: } \{0 = \text{Deceased}, 1 = \text{Survived}\}$).
* **Key Features:** `Pclass` (Ticket class: 1, 2, 3), `Name`, `Sex`, `Age`, `SibSp` (Siblings/Spouses aboard), `Parch` (Parents/Children aboard), `Ticket`, `Fare`, `Cabin`, `Embarked` (Port of embarkation: C, Q, S).

#### 2. Breast Cancer Wisconsin Diagnostic (`Data/raw/Breast_Cancer_Wisconsin.csv`)
* **Task:** Supervised Binary Classification (Malignant vs. Benign tissue screening).
* **Dimensions:** 569 rows $\times$ 33 columns.
* **Raw State:** Contains non-predictive `id` column and an empty trailing column `Unnamed: 32` ($569$ null values).
* **Target Variable:** `diagnosis` ($\text{Categorical: } \{\text{'M'} = \text{Malignant}, \text{'B'} = \text{Benign}\}$).
* **Key Features:** `radius_mean`, `texture_mean`, `perimeter_mean`, `area_mean`, `smoothness_mean`, `compactness_mean`, `concavity_mean`, `concave points_mean`, `symmetry_mean`, `fractal_dimension_mean` (along with standard error and worst-case metrics).

#### 3. Customer Churn Dataset (`Data/raw/Customer-Churn.csv`)
* **Task:** Supervised Binary Classification (Predicting customer service churn).
* **Dimensions:** 7,043 rows $\times$ 21 columns.
* **Raw State:** Contains whitespace strings (`" "`) in `TotalCharges` requiring coercion to float and non-predictive `customerID`.
* **Target Variable:** `Churn` ($\text{Binary: } \{\text{'Yes'}, \text{'No'}\}$).
* **Key Features:** Demographic attributes (`gender`, `SeniorCitizen`, `Partner`, `Dependents`), account services (`tenure`, `PhoneService`, `MultipleLines`, `InternetService`, `OnlineSecurity`, `TechSupport`, `Contract`, `PaperlessBilling`, `PaymentMethod`), and financial metrics (`MonthlyCharges`, `TotalCharges`).

#### 4. House Price Dataset (`Data/raw/HousePriceDataset.csv`)
* **Task:** Supervised Continuous Regression (Predicting residential sale price).
* **Dimensions:** 4,600 rows $\times$ 18 columns.
* **Raw State:** Unnormalized raw continuous metrics and unencoded geographical strings.
* **Target Variable:** `price` ($\text{Continuous USD}$).
* **Key Features:** `bedrooms`, `bathrooms`, `sqft_living`, `sqft_lot`, `floors`, `waterfront`, `view`, `condition`, `sqft_above`, `sqft_basement`, `yr_built`, `yr_renovated`, `street`, `city`, `statezip`, `country`.

#### 5. Palmer Penguins Size Dataset (`Data/raw/penguins_size.csv`)
* **Task:** Multi-Class Classification & Morphological Clustering.
* **Dimensions:** 344 rows $\times$ 7 columns.
* **Raw State:** Contains $18$ missing values across morphological features and corrupted period strings (`'.'`) in `sex`.
* **Target Variable:** `species` ($\text{Multiclass: } \{\text{Adelie}, \text{Chinstrap}, \text{Gentoo}\}$).
* **Key Features:** `island`, `culmen_length_mm`, `culmen_depth_mm`, `flipper_length_mm`, `body_mass_g`, `sex`.

#### 6. Cardiac Patient Monitoring Dataset (`Projects/cardiac_monitoring_project/Data/raw/heart.csv`)
* **Task:** Supervised Binary Classification (Predicting `HeartDisease`) & Unsupervised Phenotyping.
* **Dimensions:** 918 rows $\times$ 12 columns.
* **Raw State:** Contains structural missingness encoded as $0$ in `Cholesterol` ($172$ records) and `RestingBP` ($1$ record).
* **Target Variable:** `HeartDisease` ($\text{Binary: } \{0 = \text{Normal}, 1 = \text{Heart Disease Present}\}$).
* **Key Features:** `Age`, `Sex`, `ChestPainType`, `RestingBP`, `Cholesterol`, `FastingBS`, `RestingECG`, `MaxHR`, `ExerciseAngina`, `Oldpeak`, `ST_Slope`.

### 3.2 Processed Datasets (`Data/processed/`)

#### 1. Palmer Penguins Cleaned Dataset (`Data/processed/penguins_cleaned.csv`)
* **Origin:** Generated from raw `penguins_size.csv` by filtering out missing morphological values and invalid sex entries.
* **Dimensions:** 333 rows $\times$ 7 columns ($0$ missing values).
* **Status:** Fully cleaned dataset ready for direct unsupervised clustering.
* **Git Policy:** Ignored via `.gitignore` rule (`Data/processed`).

---

### 3.3 Image Benchmark Dataset (`Data/Image_dataset/`)
* **Task:** Convolutional Neural Network (CNN) Medical Image Classification (Week 7).
* **Dimensions:** 13,879 total images ($224 \times 224 \times 3$ RGB).
* **Partitions:**
  * `Data/Image_dataset/train/`: 11,879 images (6,289 Benign, 5,590 Malignant).
  * `Data/Image_dataset/test/`: 2,000 images (1,000 Benign, 1,000 Malignant).
* **Git Policy:** Ignored via `.gitignore` rule (`Data/Image_dataset`).

## 4. Standard Programmatic Ingestion Pattern

```python
import os
import pandas as pd
from pathlib import Path

# Portable relative path resolution
BASE_DIR = Path(__file__).resolve().parent if "__file__" in locals() else Path.cwd()
RAW_DATA_PATH = BASE_DIR / "Data" / "raw" / "1.TitanicDataset.csv"

# Load read-only raw data
df = pd.read_csv(RAW_DATA_PATH)
print(f"Loaded raw dataset: {df.shape[0]} rows, {df.shape[1]} columns")
```
