## <span style="color:#85C1E9">Weekly Learning Objectives</span>

- ✂️ **Data Preparation & Splitting:** Master separating features ($X$) and target ($y$), and partitioning datasets into training and testing sets with reproducible random states.

- ⚙️ **Feature Engineering & Preprocessing:** Implement feature scaling (StandardScaler, MinMaxScaler), handling missing values, and categorical encoding (One-Hot Encoding).

- 📈 **Regression Models:** Build, evaluate, and interpret Linear Regression and Polynomial Regression models using MSE, RMSE, MAE, and $R^2$ metrics.

- 🎯 **Classification Models:** Implement Logistic Regression, Decision Trees, and K-Nearest Neighbors (KNN), evaluating performance with Confusion Matrices, Precision, Recall, F1-Score, and ROC-AUC curves.

- 🛠️ **Model Evaluation & Cross-Validation:** Understand overfitting vs. underfitting and apply $k$-fold cross-validation for trustworthy performance assessment.
