# Week 2, Day 5: EDA Part 2 - Correlation & Data Storytelling

## Overview
Today's focus was on completing the **Exploratory Data Analysis (EDA)** centerpiece notebook. EDA is the systematic process of understanding a dataset before modeling — uncovering distributions, relationships, outliers, and feature interactions.

In this notebook, we performed bivariate analysis, computed a Pearson correlation matrix with an annotated heatmap, and synthesized our findings into a data storytelling narrative with modeling recommendations for the Titanic dataset.

## Repository Contents
* `Task.ipynb`: A Jupyter Notebook implementing the full Exploratory Data Analysis (EDA) pipeline on the Titanic dataset, including data cleaning, univariate boxplots, bivariate analysis, correlation heatmap, and data storytelling.
