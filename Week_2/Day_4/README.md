# Week 2, Day 4: EDA Part 1 - Distributions & Outliers
## Overview
Today's focus was on **Exploratory Data Analysis (EDA)**. EDA is a mandatory first step before modeling because it allows us to understand the structure of the data, catch potential problems, and avoid silently corrupting results downstream.
In this task, we performed univariate analysis and outlier detection on the Titanic dataset.
